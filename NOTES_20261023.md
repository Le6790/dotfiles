# Dotfiles notes, 2026-10-23

Decisions, open threads, gotchas. Read this cold in six months.

## Decisions

- **Bash is the primary shell on macOS and Linux.** The Mac login shell is Homebrew
  bash (`/opt/homebrew/bin/bash`; check with `dscl . -read /Users/$USER UserShell`).
  `.zshrc` is kept for when zsh is launched by hand. README corrected to say so.
- **pyenv init lives in both `.bash_profile` and `.zshrc`.** The two shells read
  different files, so each needs its own copy. Shims are *prepended* on purpose so
  they beat Apple's `/usr/bin/python3`; every other user dir is appended (see the
  comment in `.bashrc`). The bash copy also prepends `$PYENV_ROOT/bin`; harmless
  because Homebrew already puts `pyenv` on PATH.
- **tmux stays pinned to bash** (`default-command bash` in `.tmux.conf`), even on the
  Mac. Considered removing it so panes use `$SHELL`; rejected because bash is the
  login shell anyway and the pin keeps panes bash if zsh is started manually.
- **`src` and `hst` branch on `$ZSH_VERSION`** (`.bash_aliases`). In zsh, `src`
  sourced the wrong file (`~/.bashrc`) and bare `history` shows only the last 16
  entries, so `hst` needs `history 1`.
- **`.vimrc` is for plain vim only.** nvim uses its own Lua config in
  `~/.config/nvim` (a separate git repo), so `.vimrc` changes do not affect nvim.
- `.vimrc` notes mapping `<leader>fn` now points at `~/Documents/obsidian_brain/`
  (was the stale `~/notes/`).
- `programs_to_install.md` now lists tmux, neovim, pyenv, nvm; neofetch replaced by
  fastfetch (neofetch is archived).

- **Removed `.alacritty.yml`** (unused since moving to WezTerm; YAML config is also
  deprecated in Alacritty 0.13+). Still in git history; the installer no longer links
  it. A real `~/.alacritty.yml` in `$HOME` was left untouched.

## Open threads / deliberately skipped

- `~/.zprofile` (pipx and Flutter PATH edits, Flutter prepended) is not tracked and
  not linked by `install_symlinks.sh`. Skipped by choice; a fresh Mac loses those.
- Linux/machine-specific aliases in `.bash_aliases` (`cura`, `spt`, `disable_screens`,
  `enable_screens`) load on every machine. Skipped by choice.
- `.vimrc` maps NERDTree / fzf.vim commands but nothing installs those plugins.
- Minor: `keyboard_control.sh` shebang `#!/usr/bin/bash` is not portable; `.bashrc`
  sources `~/.bash/prompt.sh`, probably dead since starship overrides the prompt.
- Cleanup candidates in `$HOME`: `~/.zshrc.pre-oh-my-zsh` and `*_backup*` files.

## Gotchas

- `.zshrc` returns early for non-interactive shells, so its pyenv block does not
  cover scripts run under zsh. `.bash_profile` is where non-interactive env setup goes.
